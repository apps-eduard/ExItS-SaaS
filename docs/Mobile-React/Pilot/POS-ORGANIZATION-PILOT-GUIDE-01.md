# Organization POS — Pilot Operator Guide

**Audience:** Owner, Cashier, Inventory Staff  
**Pilot target:** Single-branch small store (sari-sari / small retail)  
**App:** PinoyBusinessPOS Organization Web/PWA

Keep this short. Follow the screens in the app.

---

## OWNER QUICK START

1. **Set up store** — Finish post-subscription setup (business details + optional starter products).
2. **Add branch** — Create Main Store if you do not have one yet.
3. **Add products** — Catalog → Add product (include at least one barcode and one weighted item if you sell by kilo).
4. **Add opening stock** — Inventory → product → opening stock (or receive via Direct Purchase).
5. **Add staff** — Organization → Staff → invite Cashier / Inventory Staff / Reporting User.
6. **Add supplier** — Purchasing / Suppliers → manual or connected supplier.
7. **Start selling** — Register this device if asked → open cashier shift → Sell.

**Tip:** On the “ready” setup step, use the links for open shift, opening stock, and invite staff before the first sale day.

---

## CASHIER DAILY FLOW

1. Login  
2. Select store / branch (auto if only one)  
3. Register this browser/device if prompted  
4. Open shift  
5. Sell — search, barcode, weight, quantity  
6. Checkout — **Cash**, **GCash (manual reference)**, or **Utang**  
7. Continue selling  
8. Close shift — enter counted cash when asked  

Cashiers do **not** need admin screens to sell.

**Manual GCash** means you type the GCash reference yourself. It is not an automatic GCash wallet payment.

---

## INVENTORY FLOW

1. **Receive / Direct Buy** — stock in with cost  
2. **Purchase Order receive** — when using suppliers/POs  
3. **Count** — Stock Count for variance  
4. **Waste/Loss** — damaged or expired  
5. **Stock Use** — internal use (not a sale)  
6. Review **movement history** on the product  

On a single-branch store, **Transfers** are hidden from the Inventory toolbar (need two branches).

---

## OWNER END-OF-DAY

1. Sales report (today)  
2. Payment breakdown (Cash / Manual GCash / Utang)  
3. Customer Utang outstanding  
4. Supplier Credit / payables balances  
5. Shift / cash variance  
6. Inventory warnings (low / expiring)  

Export CSV when the store has export entitlement.

---

## IMPORTANT SEPARATIONS

| Customer **Utang** | Supplier **Credit** |
|--------------------|---------------------|
| Money customers owe you | Money you owe suppliers |
| Sell → Utang | Receive / Direct Buy → Supplier credit |
| Never mix with supplier balances | Never mix with customer Utang |

---

## IF SOMETHING IS BLOCKED

| Message | What to do |
|---------|------------|
| Register this device | Owner/manager registers the POS device |
| Open shift required | Cashier opens a shift |
| No products to sell | Owner/Inventory adds products |
| Cannot reverse receipt (payments posted) | Settle/void supplier payments first, or ask manager |

Record issues with the pilot feedback template.
