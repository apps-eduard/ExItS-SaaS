# Platform Admin Web (Modernization) — Documentation Only

This documentation set establishes the baseline for a documentation-only modernization program
for the Platform Admin Web experience.

It audits the current implementation (`src/Platform/ExItS.Platform.Admin`), defines replacement
boundaries, and records a dedicated planning worktree (`docs/platform-admin-web-v2`).
