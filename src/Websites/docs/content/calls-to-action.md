## CTA Design Rules

- Primary CTA: deep emerald → bright green gradient button, white text, semi-bold
- Secondary CTA: outlined emerald border, emerald text, transparent background
- Tertiary / link CTA: text link with arrow icon (Lucide `ArrowRight`)
- All CTAs must have `:focus-visible` ring for keyboard accessibility
- CTA copy: active verbs, no "Click here"
- Maximum 2 CTAs per section (1 primary + 1 secondary)

## Prohibited CTA Labels

- "Buy Now" (incorrect for SaaS subscription context)
- "Download" (unless mobile app confirmed available)
- "Free Trial" (unless trial policy confirmed — TBD WEB-D-01)
- "Sign Up for Free" (unless free tier confirmed — TBD WEB-D-01)
