## Purpose

Compliance docs capture **open regulatory questions** and honesty rules for Philippine pawn operations. They do **not** assert that ExItS or PPM is licensed, authorized, or compliant.

## Core honesty rule

**Technical capability ≠ legal authorization.**

Building intake, tickets, interest fields, custody, or disposition workflows in software does **not** authorize a subscriber (or ExItS) to operate a pawnshop, charge particular rates, auction unredeemed goods, or skip licensing/AML/DPA obligations.
