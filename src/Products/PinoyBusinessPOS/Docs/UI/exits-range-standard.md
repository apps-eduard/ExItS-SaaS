# ExItS Range Standard

**Status:** APPROVED / LOCKED
**Scope:** `src/Products/PinoyBusinessPOS/ExItS.PinoyBusinessPOS.React`
**Visual authority:** `/ui-standards` → **Range**

**Locked global command:** the Range playground on `/ui-standards` → **Range**. New ranges are requested with `ext range`.

This standard evolves with the Range playground. Do **not** pin it permanently to a commit SHA.

## Command

Defaults are omitted. `ext range` is Standard intent, step 1, values 20–70, no label, no markers, no drag, enabled.

```
ext range [intent] [step <n>] [label] [label-always] [markers] [drag] [disabled]
```

Example: `ext range drag`

## Samples

Standard, Label, Markers, Drag range, and Disabled. Each thumb moves on its own. Drag range moves the selected span.
