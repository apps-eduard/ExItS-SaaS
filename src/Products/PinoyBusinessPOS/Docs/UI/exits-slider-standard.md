# ExItS Slider Standard

**Status:** APPROVED / LOCKED
**Scope:** `src/Products/PinoyBusinessPOS/ExItS.PinoyBusinessPOS.React`
**Visual authority:** `/ui-standards` → **Slider**

**Locked global command:** the Slider playground on `/ui-standards` → **Slider**. New sliders are requested with `ext slider`.

This standard evolves with the Slider playground. Do **not** pin it permanently to a commit SHA.

## Command

Defaults are omitted. `ext slider` is Standard intent, step 1, value 40, no label, no markers, no snap, horizontal, enabled.

```
ext slider [intent] [step <n>] [label] [label-always] [markers] [snap] [vertical] [disabled]
```

Example: `ext slider primary markers`

## Samples

Standard, Label, Markers, Snap, Vertical, and Disabled. Standard intent uses the same gray as checkbox Standard.
